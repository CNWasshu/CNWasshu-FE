# 타임테이블 설치 패키지

## React Native DateTimePicker

타임테이블의 Android/iOS 출발일 및 도착일 선택을 위해 다음 패키지를 설치했습니다.

```text
@react-native-community/datetimepicker
```

관련 설정 파일:

```text
package.json
package-lock.json
app.json
```

브랜치를 처음 받은 팀원은 프로젝트 루트에서 다음 명령을 실행해 주세요.

```bash
npm ci
```

이미 의존성을 설치한 환경에서 패키지를 갱신하려면 다음 명령을 사용할 수 있습니다.

```bash
npm install
```

`node_modules/`는 Git에 커밋하지 않습니다.
