# 타임테이블 프론트엔드 작업 계획

## 작업 개요

충남왔슈에서 사용자가 여행 기간을 설정하고 날짜와 시간대별 일정을 구성할 수 있는 타임테이블 프론트엔드를 구현합니다.

HTML 목업을 참고하여 모바일과 웹의 반응형 화면을 기준으로 작업합니다. 공통 하단 네비게이션은 타임테이블 구현 범위에서 제외합니다.

## 작업 기준

- 이 문서의 체크리스트를 타임테이블 프론트엔드 작업 기준으로 사용합니다.
- 작업이 완료될 때마다 체크박스와 실제 커밋 메시지를 갱신합니다.
- 작업 범위나 구현 방향이 변경되면 이 문서를 함께 수정합니다.
- 하나의 PR은 독립적으로 검토 가능한 기능 단위로 제한합니다.
- 커밋과 PR 제목은 `type(scope): 작업 내용` 형식을 사용합니다.
- 프론트엔드 코딩 컨벤션과 SOLID 원칙을 준수합니다.
- 화면, UI, 상태 관리, 타입, 유틸리티 및 API 통신의 책임을 분리합니다.
- Git 명령 실행과 커밋·푸시·PR 관리는 작업자가 직접 진행합니다.

## 화면 문구 및 목업 사용 기준

목업은 타임테이블의 전체적인 화면 구성과 사용자 흐름을 확인하기 위한 참고 자료입니다.

다음 요소는 최종 확정 사항이 아닙니다.

- 화면 제목과 설명
- 버튼 이름
- `장바구니` 등의 메뉴 명칭
- 안내 및 오류 문구
- 색상과 간격
- 일정 추가 및 저장 흐름
- 아이콘과 세부 UI

화면 문구와 UI는 충남왔슈의 서비스 방향성, 팀 협의, 실제 기능 요구사항 및 백엔드 API 명세에 따라 변경할 수 있습니다.

목업의 `장바구니` 탭은 타임테이블 진입 화면을 의미하는 참고 표현입니다. 공통 하단 네비게이션은 별도 작업에서 `/timetable` 경로와 연결합니다.
